# norte-de-caja

Prototipo interactivo para explorar distintas visiones de "north star" de la caja de búsqueda de Despegar.

Incluye un **panel de control** (Vision Explorer, ícono ⚙ a la derecha) que permite alternar entre presets de visión y toggles individuales para imaginar hacia dónde podría evolucionar el producto:

- **Presets:** (a) SOFIA-led · (b) Caja clásica · (c) Box-on-home
- **Toggles:** barra de búsqueda, shifu en home, SOFIA en shifu, patrón de navegación de SOFIA (tabs fijas / segmentado / side-nav / side-nav +), acceso a Disney y Universal
- Cada configuración queda guardada en la URL → **link compartible**

Prototipo de una sola página, vanilla JS (sin framework): `index.html` · `app.js` · `styles.css`.

## Ver localmente

Abrir `index.html` en el navegador.
